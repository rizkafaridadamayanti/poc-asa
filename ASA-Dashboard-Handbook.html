Peta lengkap setiap layar, form, dan tombol di ASA Dashboard

ASA Dashboard adalah panel admin untuk bot WhatsApp Karang Taruna — mulai dari login sampai menu terakhir di sidebar. Dokumen ini merunut tiap halaman satu per satu: apa yang tampil, form apa yang diisi, dan tombol mana yang melakukan apa.

Kerangka tetap (setelah login)

Muncul di semua 9 menu sidebar — tidak berubah antar halaman.

Topbar

  • Logo + judul ASA Dashboard / subjudul "WhatsApp Bridge — Karang Taruna"
  • Badge status: ● WA Connected / WA Disconnected / Syncing…
  • Tanggal hari ini (format Indonesia)
  • Menu akun (avatar inisial + nama + role "ADMIN PUSAT") → Logout
  • Tombol hamburger (mobile) buka sidebar sebagai offcanvas

Sidebar

  • 9 tautan menu (Dashboard → Antrian Ide), tiap item warna ikon beda
  • Tombol collapse/expand (ikon panah, tersimpan di localStorage)
  • Tombol Logout di bagian bawah

Notifikasi live (toast)

  • "WhatsApp connected" / "WhatsApp disconnected" saat status bot berubah
  • "New message from …" tiap ada pesan masuk baru (real-time via SSE)
  • Toast error kalau koneksi live terputus

03 /

Dashboard

"Selamat pagi/siang/sore/malam, {nama}!" — ringkasan aktivitas bot hari ini.

Yang tampil

  • Kartu koneksi bot — kalau belum tersambung: instruksi + QR code untuk discan dari WhatsApp (Setelan → Perangkat Tertaut), tombol Refresh QR. Kalau sudah tersambung: badge "Connected", nomor & nama perangkat, ikon platform (Android/iPhone)
  • 3 stat card (muncul hanya saat bot connected): total pesan masuk, jumlah ringkasan dibuat, jumlah kontak aktif — tiap kartu punya progress bar
  • Peak chat hours — mini grafik batang 24 jam + tautan "Lihat detail" ke Infografis
  • Kartu "Getting started" — tips memakai Send/Messages/Digest
  • Distribusi Grup — donut chart (Pusat / Dusun / Anggota / Belum diatur)
  • Kalender aktivitas — kalender bulan berjalan, navigasi bulan sebelumnya/berikutnya, tanggal dengan aktivitas ditandai titik (pesan terkirim / terjadwal) — klik tanggal buka modal detail aktivitas hari itu
  • Kartu Sentiment Harian Pusat — laporan sentimen harian terakhir dari AI (kalau ada)

Tombol & interaksi

LabelJenisEfek
Refresh QRPrimerMinta ulang QR code terbaru dari server
‹ / › (navigasi kalender)SekunderPindah bulan sebelumnya/berikutnya
Klik tanggal aktifSekunderBuka modal "Aktivitas {tanggal}" — daftar pesan terkirim & item terjadwal hari itu
Lihat detail (Peak hours)TautanPindah ke halaman Infografis

07 /infografis

Infografis

Halaman statistik murni — tidak ada form atau aksi tulis, semuanya baca-saja.

Yang tampil

  • Peak chat hours — grafik batang 24 jam lengkap dengan sumbu-Y dan tooltip per jam
  • Active vs contributive — tabel partisipan: jumlah pesan (ikon chat) & jumlah pesan bertanda ide (ikon bohlam)
  • Groups by dusun — tabel jumlah grup per dusun

Tidak ada tombol interaktif di halaman ini selain hover tooltip pada grafik batang.

10 /spam-alerts

Spam / Fraud Alert

Pesan yang lolos heuristik spam-fraud (skor ≥ 50) — otomatis dikirim ke Pusat lewat WA, halaman ini untuk menindaklanjuti.

Tiap kartu alert

  • Badge skor ("Skor 72/100")
  • Isi pesan lengkap + pengirim + chat asal
  • Tag alasan heuristik (mis. "link mencurigakan")
  • Penanda "sudah dikirim ke Pusat" kalau notifikasi WA sudah terkirim

Filter

  • Baru (open, default)
  • Dikonfirmasi spam
  • Bukan Spam (dismissed)
  • Semua

Tombol (khusus status "Baru")

LabelJenisEfek
Konfirmasi SpamBahayaTandai sebagai spam terkonfirmasi, keluar dari daftar "Baru"
Bukan SpamSuksesTandai sebagai bukan spam (dismissed), keluar dari daftar "Baru"
